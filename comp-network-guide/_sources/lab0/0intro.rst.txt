实验简介
==================================================

实验内容与要求
--------------------------

本学期计算机网络实验总计12学时，分6次开展（每次2学时）。实验内容分为 **配置验证型** 和 **编程设计型** 两类，共包含9个小实验。

配置验证型实验
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**该类实验共 3 次课，每次完成后需进行现场验收**，核心目标是掌握网络设备的基础配置与协议验证方法。

**实验内容**：VLAN与接口模式配置、RIP路由配置及协议分析、IPv6网络过渡实验。

**实验要求**：验证型实验需在本课程提供的实验环境中完成。在开始实验前，请先阅读 :doc:`/appendix-c/index`，了解网络实验室布局及设备的基本使用方法，以便更好地理解和完成实验任务。

协议栈编程设计型实验
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

该类实验为递进式开发任务，最终需完成小型 Web 服务器搭建，重点锻炼网络协议的编程实现能力。

**实验内容**：在本课程提供的代码框架上，依次实现以太网收发 → ARP解析 → IP实现 → ping响应 → UDP收发 → TCP收发 → HTTP协议，最终搭建属于你自己的小型Web服务器！

**实验环境**：网络编程实验环境的安装与配置详见附录B :doc:`网络编程实验环境 <../appendix-b/index>` 。

**实验提交**：协议栈实验的提交要求与自检步骤见 :doc:`/submission/index`。

.. important::
   正式开始协议栈实验前，请先完成 :doc:`/appendix-b/0checklist`。

   若你在实验过程中反复遇到环境兼容性、校验和、ARP 表、TCP 序列号等问题，请优先查阅 :doc:`/appendix-g/0bug-handbook`，再回到对应实验章节继续排查。

实验课课表
--------------------------

若存在课程时间冲突，可参考课表自主调整，具体规则如下：

- 时间冲突处理：优先按原课表上课，确有冲突时可选择课表中的其他时段。
- 调整要求：选定新时段后，**必须提前联系实验任课老师**，确认上课安排。
- 重要提醒：未提前沟通擅自调整时段，将视为缺课，影响实验成绩。
